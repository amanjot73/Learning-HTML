Then Why Let and Var?

In early time, there was one problem in js i.e the block scope
When user uses var in a loop and after the loop if again write that var it changes its value

eg =>

    int k = 19;
}
k = 20;
undating the k....That's the error which was there
So then the programmers decided not to use <<<<<Var>>>>>
